# Interactive Flashcard Maker

A simple interactive flashcard maker built with HTML, CSS, and JavaScript. Create and flip cards with smooth animations for an engaging study experience!

## Features

- **Dynamic Flashcard Creation:** Enter questions and answers to generate flashcards.
- **Interactive Flip Animation:** Click on a flashcard to reveal its answer with a smooth flip effect.
- **Responsive Design:** Optimized for both desktop and mobile use.
- **Clean & Minimal UI:** A non-distracting interface perfect for focused learning.
